# 제주숲홍차 프로모션 홈페이지

“오늘의 쉼표, 제주를 건네다” 콘셉트의 반응형 단일 페이지 시안입니다. HTML5, CSS3, 순수 JavaScript로 구성되어 별도 빌드 도구 없이 실행할 수 있습니다.

## 실행 방법

1. ZIP을 압축 해제합니다.
2. `index.html`을 브라우저에서 엽니다.
3. 일부 브라우저의 보안 설정으로 로컬 파일에서 이미지가 보이지 않으면 폴더를 정적 호스팅에 올려 실행하세요.

## 파일 구성

- `index.html` — 페이지 구역과 콘텐츠
- `css/style.css` — 색상, 레이아웃, 반응형 및 모션
- `js/script.js` — 스크롤 연혁, 모바일 메뉴, 우림 탭·영상 자막, 스크롤 등장 효과
- `assets/images/` — 메인, 연혁, 제품, 티타임, 선물 이미지 및 우림 영상 컷
- `assets/videos/` — 티백·잎차별 4단계 무음 우림 영상
- `ASSET_SOURCES.md` — 이미지 생성 및 사실 확인 출처

## 인터랙션 참고

메인 타이틀 리빌, 히어로 차밭 패럴랙스·안개 레이어, 스크롤 연동 연혁은 Bright Biotech 사이트의 큰 메인 이미지와 순차적 스크롤 흐름을 참고해 구현했습니다. 원본 디자인을 복제하지 않고 제주숲홍차 캠페인에 맞게 별도 구성했습니다. 상단 메뉴는 hover/focus 시 1.08배 확대되고 티빛 앰버로 색상이 바뀌며, 구매 버튼은 앰버 배경으로 강조됩니다.

## 주요 수정 위치

- 상단 메뉴와 구역 이동: `index.html`의 `.site-nav` 링크 및 각 `section id`
- 메인 이미지: `assets/images/hero-jeju-tea-field.png` 교체
- 역사 장면 이미지: `history-1979.png`, `history-1980.png`, `history-1984.png`, `history-2001.png`, `history-today.png` 교체
- 연혁 문구와 표시 순서: `js/script.js`의 `milestones` 배열 및 `index.html`의 이미지 순서를 함께 수정
- 제품 카드 이미지: `product-teabag-10.png`, `product-leaf-80g.png` 교체
- 티타임·선물 이미지: `tea-time.png`, `gift-from-jeju.png` 교체
- 우림 영상: `assets/videos/brew-teabag.mp4`, `assets/videos/brew-leaf.mp4` 교체. 두 파일은 각각 티백/잎차의 준비 → 물 붓기 → 우리기 → 따르기 순서입니다.
- 색상과 반응형 레이아웃: `css/style.css` 상단 `:root`와 미디어 쿼리
- 공식 구매 주소: `index.html`에서 `osulloc.com` 링크를 검색해 원하는 상품 링크로 수정
- 우림 정보와 자막: `index.html`의 `#brew` 구역 및 `js/script.js`의 `brewSequences`를 함께 수정

## 콘텐츠 정확도 안내

연혁은 오설록 공식 연혁에 있는 1979, 1980, 1984, 2001년 주요 항목을 바탕으로 했습니다. ‘오늘’은 제품 캠페인 연결 장면입니다. 역사 이미지는 실제 기록 사진이 아니라 장면 재현 이미지입니다.

제품 카드 이미지는 콘셉트 연출 이미지입니다. 10입 티백 이미지는 실제 패키지 사진이 아니며, 80g 잎차 이미지는 마른 잎차와 우림 도구를 보여주는 연출 컷입니다. 실제 판매 목적의 공개 페이지에서는 `assets/images/`의 제품 이미지를 오설록 공식 상품 사진으로 교체하세요. 현재 구매 버튼은 오설록 공식 상품 페이지로 연결됩니다. 가격은 변동될 수 있으므로 별도 고정 표시하지 않았습니다.

우림 안내는 공식 상품 페이지의 표시를 기준으로 작성했습니다. 티백 1개 또는 잎차 1 테이블스푼, 90°C 물, 2분 우림입니다. 상품 안내가 변경되면 해당 구역의 문구도 확인해 주세요.

우림 영상은 각 4컷을 짧게 이어 붙인 콘셉트 연출 영상이며 실제 2분 우림을 실시간으로 재현하지 않습니다. 티백 영상과 잎차 영상은 별도 장면으로 구성했고, 탭을 바꾸면 해당 영상과 단계 자막도 함께 바뀝니다. 영상 재생은 자동으로 시작되며, 영상 우측 상단 버튼으로 일시정지/재생할 수 있습니다.
